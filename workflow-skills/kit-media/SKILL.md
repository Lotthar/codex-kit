# Kit media

For ordinary image generation or editing, use the available native image tool. Choose a connected provider plugin when it fully serves a requested provider-specific task; keep the work within the user's stated scope.

For a Higgsfield creator brief needing a visual treatment, shot plan, or staged reference review, consult `$higgsfield-creative-director`; preserve any explicitly invoked provider command and its routing requirements.

For existing authorized footage that needs cuts, captions or audio finishing, use `$video-edit` when available. Use `$video-motion` for editable typography, diagrams or compositing, and `$video-review` for critique of an existing export. The active project production workflow controls brand, budget, approval and publication decisions.

Provider training, publishing, deployment, paid generation, account changes, login, installation, and purchases require user authorization; proceed when it is already in scope, but do not initiate them automatically. Keep every `$skill-name` direct call available; consult focused legacy guidance only when needed, and do not start its setup, specification, ticket, review, or publish workflow unless the user requests it.

Keep assets, prompts, and external actions scoped to the request. A website in an existing repository is engineering/UI work, not a media-provider task. Always follow mandatory external-platform skills when their platform or tool is in scope.
